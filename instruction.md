## 🔧 Настройка Outline Manager

### Шаг 1: Загрузка и установка
1. Загрузите Outline Manager с официального сайта: https://getoutline.org/ru/get-started/#step-1
2. Установите и запустите приложение

### Шаг 2: Подключение к серверу
1. При запуске менеджера выберите опцию **"Set up Outline anywhere"**
2. В появившемся окне найдите поле **"Paste your installation output here"**
3. Вставьте следующий код конфигурации:

```json
{"apiUrl":"https://194.87.187.45:35827/vWBzNPyVfFf1oG5qVqaYbw","certSha256":"9B4C55513E55EAB8AF7073FE1AA20FCE634346DC50FEEFA130BAD5750E730DED"}
```

4. Нажмите **"Done"** для завершения настройки

## 📱 Установка Outline Client

### Назначение
Outline Client необходим для тестирования созданных VPN ключей и проверки их корректной работы.

### Установка
1. Загрузите Outline Client: https://getoutline.org/ru/get-started/#step-3
2. Установите приложение согласно инструкциям для вашей операционной системы
3. Используйте стандартный процесс подключения через VPN ключи

## ✅ Сценарии тестирования

### 1. Основные функции управления ключами

#### Создание и выдача ключей
- [ ] Запросить новый VPN ключ
- [ ] Проверить корректность выдачи ключа пользователю
- [ ] Убедиться, что пользователь появился в административной панели
- [ ] Проверить правильность обработки данных в системе

#### Безопасность и изоляция
- [ ] Проверить, что ключ привязан только к конкретному пользователю
- [ ] Убедиться, что другие пользователи не видят чужие ключи
- [ ] Протестировать корректность работы системы авторизации

### 2. Миграция существующих пользователей

#### Функционал миграции
1. Перейдите на страницу: https://vpnconsoleoutline.tw1.ru/vpn-clients
2. При создании нового пользователя укажите существующий VPN ключ для ассоциации
3. Проверьте корректность привязки ключа к пользователю

> **⚠️ Известная проблема:** В настоящее время наблюдается проблема с эндпоинтами (ошибка 500), которая связана с настройками деплоймента. Исправление планируется в ближайшее время.
